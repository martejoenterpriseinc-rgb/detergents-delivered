# CPA financial event ledger

The CPA Center links to `/admin/cpa/ledger`. ADMIN, SUPER_ADMIN and CPA may read or export the report; customer access is denied. The server rechecks the current identity and role in a read-only repeatable database transaction. The JSON/CSV endpoint is `/api/admin/reports/ledger`; it has no mutation method and calls no provider.

The report selects current-environment USD paid checkout orders, their refund adjustments and stock returns. Sales use the original placed date, refund adjustments their recorded settlement/compensation date, and returns their received date, each interpreted as a Chicago business date. Date boundaries include daylight-saving transitions. Filters support a maximum one-year range, optional single-order scope, and 50-row pages. Totals cover every event in the range; CSV exports the entire selected range. More than 250 combined events requires a narrower range and returns no partial report. This is a bounded review/export, not an unbounded general ledger extraction.

Original sales reuse strict saved checkout, item, tax, payment, reward and audit evidence. Refunds reuse the signed settlement/reversal source verifier. Costs reuse immutable consumed FIFO allocations and return-condition evidence. Current catalog prices, tax rates and reward balances never reconstruct history. Missing evidence yields blank amounts and review counts; it cannot silently become an accepted zero. Database failures abort the report. Incomplete financial or cost evidence suppresses the merchandise-minus-cost subtotal.

Positive cash represents original payment or a failed-refund reversal; settled refunds are negative. Reward redemption is negative and restoration positive. COGS is positive at sale and negative for sellable returned stock; damaged returns restore zero cost. Stock receipt does not itself move cash, tax or reward credit. Original merchandise/promotion columns apply only to sales. Matched refund tax evidence remains separate from locally allocated tax; pending provider tax matching stays visible. These totals are not bank settlement, profit, a tax filing or a full financial statement. Manual payments, tips, operating expenses and unrelated reward awards are outside this report.

CSV is private/no-store, formula-escaped, and excludes provider IDs and private checkout/address metadata. Sources are read in one repeatable snapshot. No new migration, external configuration, deployment or provider acceptance is part of this increment.

Coverage: focused tests exercise combined bounds, pagination/export totals, DST, access-before-read, unknown cost and database failure propagation. Native PostgreSQL cases verify actual sale evidence, current environment isolation, missing evidence, independent sellable/damaged return costs, signed refunds/reversals and unchanged audit history. Browser coverage exercises CPA login, amounts, private CSV, unsupported writes, refresh, missing/empty states and all three viewports. Synthetic fixtures are isolated CI evidence only. Exact full CI/source results belong in the release PR.
